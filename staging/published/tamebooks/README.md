# TameBooks — Simple Bookkeeping Software for Small Business

Complete small-business accounting app in a single file. Open it in any
browser, on any computer — no install, no account, no internet needed.
Real double-entry bookkeeping under the hood, plain English on the surface:
money in, money out, who owes me, what I owe.

## What's inside
- `index.html` — the complete app. Single file, works offline.
  Open it in any modern browser (double-click, or File → Open). No install,
  no account, no internet needed.
- `tamebooks-1.0.0.zip` — the ZIP uploaded to Gumroad (contains only index.html).
- `gallery/` — 7 screenshots showing the app in action, plus `covers/`
  (Glen-approved square thumbnail #32, 1080×1080 — ships exactly as approved).

## Features
- Invoices with Draft / Sent / Paid / Overdue tracking, partial payments, overdue reminders
- Bills and bill payments, expenses with receipt photo attachments
- Profit & Loss, Balance Sheet, Cash Flow reports — click any number to see the entries behind it
- "Who owes me" / "Who I owe" aging views, tax summary, Trial Balance, full journal
- Bank statement import (CSV, OFX, QIF) with matching and categorization
- Recurring invoices, budgets, inventory with cost-of-goods tracking, mileage,
  time tracking, fixed assets, multiple currencies, multiple companies
- JSON backup & restore, complete CSV export, dark mode, keyboard accessible
